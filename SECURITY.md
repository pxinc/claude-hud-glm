# Reporting a vulnerability

Do not include API keys, credentials, or sensitive usage data in a public issue.

If the repository's [Security page](https://github.com/pxinc/claude-hud-glm/security) offers **Report a vulnerability**, use it to send a private report. If it does not, open an issue requesting a private contact without including vulnerability details or secrets.

Include the affected revision, reproduction steps, and impact in the private report. Check the current `main` branch before reporting. A support policy for older versions has not been defined.
