# Upstream and references

- [jarrodwatts/claude-hud](https://github.com/jarrodwatts/claude-hud), MIT. This adapter dynamically imports the user's separately installed HUD. Upstream source files and images are not vendored here. HUD's original license remains with that installation.
- [Darkycl/claude-code-glm-statusline](https://github.com/Darkycl/claude-code-glm-statusline), MIT. An early design reference for GLM quota status lines; its installer and session scanner are not included in this project.
- [zai-org/zai-coding-plugins](https://github.com/zai-org/zai-coding-plugins), Apache-2.0. Reference for the official usage-monitor endpoint and authentication convention. The official plugin and its scripts are not bundled.

The quota-fetching, caching, adapter, and setup code in this repository was developed for this project. Product names belong to their respective owners.
